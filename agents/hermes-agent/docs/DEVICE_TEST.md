# 真机测试记录（Hermes 客户端 · 开发骨架）

设备：国内版 Rokid Glasses，YODAOS-Sprite；Rokid AI Android。

本页用于验证**开发骨架「Hermes 客户端」**：语音唤起应用，唯一物理操作是确认键（查看/刷新接入状态）。

> **骨架性质**：Hermes **当前尚未接入**。本应用不连接任何端点、不调用模型、不做推理，界面只显示「Hermes 尚未接入」。**绝不**声称"已接入/可推理/可用模型"。

## 操作模型与约束（硬约束）

- 语音唤起应用；**确认键为唯一物理操作**。不依赖方向键、触摸或菜单选择。
- 页面无可选择标签、无方向键导航、无并列功能入口。
- 确认：查看/刷新接入状态。Enter/GlobalHook 均视为确认；其他按键不承担选择。
- 错误详情限一行，可读，不泄露任何敏感数据。

## 权限

- 无（Hermes 尚未接入；未来接入时按需声明）。

## 边界（关键）

- 本骨架**不**报告设备能力 `ok/unsupported/failed`（那属于 `system-diagnostics`）。
- 本骨架**不**检测相机视觉状态（那属于 `combat-power-detector`）。
- 未来接入 Hermes 需另立实现并重新标注，不属于当前骨架。
