# 真机测试记录（应用测试 · 设备系统测试）

设备：国内版 Rokid Glasses，YODAOS-Sprite；Rokid AI Android。

本页用于验证**设备系统测试「应用测试」**：对眼镜说“应用测试”唤醒应用，唯一物理操作是确认键（开始/停止/重试）。一次诊断按固定顺序执行五项核心能力：**① 运行时基础 API → ② 语音识别 zh-CN → ③ 相机（live video）→ ④ 扬声器/语音合成 → ⑤ 公网 HTTPS 基线**。

> **系统测试性质**：本应用**不**判断人体/身份/危险/杀伤力，**不**给出"战斗力数值"，也**不**声称"所有硬件已通过"。总结果只能是「设备能力诊断完成 / 部分通过 / 失败 / 未完成」，每项能力如实标 `ok / unsupported / failed`。设备能力 ok/unsupported/failed 只有本系统测试 Agent 才能报告。

## 操作模型与约束（硬约束）

- 语音唤起应用；**确认键为唯一物理操作**。不依赖方向键、触摸或菜单选择。
- 页面无可选择标签、无方向键导航、无并列功能入口。
- 确认：空闲=开始；运行中=停止；完成/失败=重试。Enter/GlobalHook 均视为确认；其他按键不承担选择。
- Backspace 仅在退出/返回前清理（停止并释放相机媒体轨、语音识别与网络请求）。
- 错误详情限一行，可读；不泄露设备标识、照片字节、完整转写或响应正文。

## 权限

- `RECORD_AUDIO`：仅在确认键动作后用于语音识别会话。
- `CAMERA`：仅在确认键动作后 `getUserMedia({ video: true })`。
- `INTERNET`：仅用于公网 HTTPS 基线（状态码+耗时）。

## 总体结果 vs 每项状态

- **设备能力诊断完成**：五项核心能力全部 `ok`。
- **部分通过**：至少一项 `ok`，但不是全部。
- **诊断失败**：无一项 `ok`（全部 unsupported/failed）。
- **诊断未完成**：运行中被确认键停止，或未完成。

> 该结果只反映"设备能力诊断"，**不代表**战斗/身份/健康结论，也**不代表**所有硬件一定都已正常工作。

## 常见问题的诚实标注

- 若语音识别 API 或语音合成在当前 AIUI 运行时不暴露（`SpeechRecognition`/`speechSynthesis` 为 `undefined`），对应步骤如实显示 `unsupported`，**不会**被当作真实硬件故障。
- 语音合成**仅做表面探测**，不自动播放，因此"扬声器实际发声是否正常"属于**未验证真机项**，需另行测试（见 README）。

## 隐私

- 相机/录音仅在确认键动作且权限已声明后使用；用毕立即停止释放。
- 不保存、不上传照片字节或完整语音转写；不显示实时取景画面。
- 网络探测只读状态与耗时，不读响应正文。
- 真机日志/截图请不要包含序列号、MAC、token、Hermes key、完整语音内容或照片内容。
