# 真机验证矩阵（应用测试 0.3.1）

设备：国内版 Rokid Glasses / YodaOS-Sprite；Rokid AI Android。

## 目标

验证 42 项 / 10 类 AIUI 应用层能力基线。结果按证据等级记录，不再使用“全部核心能力已通过”。

## 推送前

- [ ] Studio 从最新 GitHub 子目录导入并打包。
- [ ] 下载 AIX，核对 `app.json = 0.3.1` 与 `CapabilityCatalog`。
- [ ] 删除/重建 Studio 项目后完全重启 Rokid AI App，清理旧 Agent ID 缓存。
- [ ] 眼镜页面实际显示 `0.3.1`。
- [ ] 权限声明包含 `RECORD_AUDIO / CAMERA / INTERNET / GEOLOCATION`。

## 交互与显示

- [ ] 480×352 单绿屏无重叠。
- [ ] 只有确认键：执行全部 / 停止 / 重试。
- [ ] 单次物理确认即使产生 `Enter + GlobalHook` 也只触发一次。
- [ ] 结果每 4 秒自动翻页，共约 5 页；无方向键菜单。
- [ ] 临时 `onHide` 不取消诊断；退出/卸载才清理资源。

## 证据等级

- `实证`：真实闭环或有效读数。
- `表面`：API 存在但未完成外部闭环。
- `不支持`：运行时没有公开 API。
- `无接口`：AIUI 层没有入口，属于 Native/CXR-S 或未公开系统信息。
- `失败`：权限、调用、采样或超时失败。
- `未执行`：需要外设、样本或对照环境。

## 隐私核对

- 不显示/保存 deviceId、序列号、MAC、经纬度、完整转写、照片字节、条码内容或响应正文。
- 存储探针只写固定 `1` / `ok`，用毕删除。
- 真机截图不得包含账号、设备唯一标识或精确位置。
