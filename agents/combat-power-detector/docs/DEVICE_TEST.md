# 真机测试记录（战斗力检测器 · 原型）

设备：国内版 Rokid Glasses，YODAOS-Sprite；Rokid AI Android。

本页用于验证**原型「战斗力检测器」**：语音唤起应用，唯一物理操作是确认键（开始/停止/重试）。一次检测按顺序执行：**① 相机 API 探测 → ② 权限 → ③ 实时画面（live video track）→ ④ 快照证据（可选）**。

> **原型性质**：本应用**不**判断人体/身份/危险/杀伤力，**不**给出"战斗力数值"。界面与日志必须标注「原型」。**诚实判定**：只有取到一条 `live` 视频轨才显示「相机可用（原型）」；权限被拒/无相机设备/无 live 视频轨都**不算**成功。

## 操作模型与约束（硬约束）

- 语音唤起应用；**确认键为唯一物理操作**。不依赖方向键、触摸或菜单选择。
- 页面无可选择标签、无方向键导航、无并列功能入口。
- 确认：空闲=开始；运行中=停止；完成/失败=重试。Enter/GlobalHook 均视为确认；其他按键不承担选择。
- Backspace 仅在退出/返回前清理（停止并释放相机媒体轨）。
- 错误详情限一行，可读；不泄露设备标识、照片字节或序列号。

## 原型边界（关键）

- 名称虽为"战斗力检测器"，但**不得**判断人体/身份/危险/杀伤力，**不得**给出"战斗力数值"。
- 它只证明：相机 API 存在、权限可授予、能取到实时画面。
- 若未来接入离线或 Hermes 视觉模型，需另立为独立能力并重新标注，不属于当前原型。

## 隐私

- 相机仅在确认键动作且权限已声明后使用；用毕立即 `track.stop()`。
- 不保存、不上传照片字节；不显示实时取景画面。
- 真机日志/截图请不要包含序列号、MAC、token、Hermes key 或任何照片内容。
